# Comparative analysis

Set the alternatives, decision context, and criteria before collecting detail.
Normalize time frame, population, version, and measurement conditions so a
comparison is actually like-for-like. Give each criterion evidence, not a vague
score; call out missing data and criteria that matter differently to different
stakeholders.

Separate comparison from recommendation. Explain the trade-off each alternative
makes, then state any conditional recommendation and its assumptions. Use
`web-research` or `evidence-evaluation` when inputs need external discovery or
verification; use Council only if a consequential choice remains genuinely
ambiguous after the analysis.
