# Zandi skills

Skills are concise, reusable guidance that loads **on demand**.

- **DOMAIN** — expert knowledge to use.
- **REASONING** — how to deliberate.
- **WORKFLOW** — how to execute a repeatable task.
- **ASSURANCE** — how to challenge or verify a result.
- **META** — how skills and context are created or evaluated.

A skill must solve a repeated real problem. Keep it small: no giant `SKILL.md`; place deep references in `../library/` and open them only when needed. Do not blindly install community skills: inspect source and scripts first. Skills are **TESTED before TRUSTED** and should reduce future context or work, not add bureaucracy.

Lifecycle: `DRAFT → TESTED → TRUSTED → STABLE`.
