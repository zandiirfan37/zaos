# Argumentation

State the conclusion and distinguish descriptive, causal, normative, and
interpretive claims. Map the reasons and evidence that bear on each claim, make
key definitions and assumptions visible, and test the strongest plausible
counterargument before rejecting it. Calibrate the conclusion to what the
premises warrant; identify uncertainty and competing values instead of hiding
them in rhetoric.

Seek clarity before victory. Improve the argument by repairing warrants,
scope, evidence, or objection handling, not by piling on assertions. Use
`web-research` or `evidence-evaluation` when premises need external support;
use `editorial-review` when the main need is prose-level reader effect.
